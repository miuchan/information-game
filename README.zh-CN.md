# 信息元胞

[English README](./README.md)

在线体验：[https://ig.strangeattractor.life/](https://ig.strangeattractor.life/)

信息元胞是一个关于：

> 信息传播 + 信念演化 + 声誉竞争 + 网络变形

的社会元胞自动机游戏原型。

关键做法不是把完整的经济学或贝叶斯模型直接搬进游戏，而是把它压缩成一组“局部、离散、同步更新”的规则。这样它就不再像一篇论文，而像一个会自己长出舆论团块、极化裂缝、信息瀑布、谣言波前和信誉中心的社会自动机。

## 元胞自动机解释

经典元胞自动机有三件事：

- 空间是离散格子
- 每个格子有有限状态
- 下一时刻只由邻域决定

信息元胞把这些要素映射为社会信息系统：

- 格子：信息主体
- 邻域：它能看到谁
- 状态：信念、消息、行动、声誉、类型、过滤器
- 更新规则：根据信号和邻居消息改变状态

它不是物理沙盒，而是社会传播自动机：混合了生命游戏式的局部更新、传染病模型的扩散、舆论模型的信念跃迁和经济博弈中的激励冲突。

## 形式化状态模型

每个格子 `i` 存储一个压缩状态向量：

```text
X_i = (b_i, m_i, a_i, r_i, t_i, f_i, e_i)
```

其中：

- `b_i in {-2, -1, 0, 1, 2}` 是信念。
- `m_i in {-1, 0, 1}` 是当前对外消息。
- `a_i in {0, 1}` 是最终行动。
- `r_i in {0, ..., 9}` 是声誉。
- `t_i` 是主体类型。
- `f_i` 是认知过滤器或偏见。
- `e_i` 是发言能量。

### 信念

```text
b_i = -2  坚信状态为 0
b_i = -1  偏向 0
b_i =  0  不确定
b_i =  1  偏向 1
b_i =  2  坚信状态为 1
```

离散信念让模拟保持可读、可玩，同时仍然保留有意义的不确定性。

### 消息

```text
m_i = -1  发出否定 / 反 1 消息
m_i =  0  沉默
m_i =  1  发出肯定 / 支持 1 消息
```

消息故意和信念分离。主体可以相信一件事、说另一件事，或者选择沉默。

### 行动

```text
a_i in {0, 1}
```

行动表示主体最终做什么：投票、加入、购买、卖出、支持、反对、转发或忽略。真相分使用行动层计算。

### 声誉

```text
r_i in {0, ..., 9}
```

高声誉主体对邻居影响更大。声誉会在局部结果揭示后变化。

### 类型

主体异质性是系统能活起来的关键。当前类型包括：

- 求真者：只有确信时才发言。
- 从众者：跟随局部多数压力。
- 投机者：追逐注意力和影响力。
- 顽固者：抵抗信念改变。
- 核查者：收到更强的真实信号。
- 机器人：推动固定策略性消息。
- 煽动者：偏好强烈或极端表达。

如果没有类型差异，系统很容易退化成普通颜色扩散。

### 过滤器

`f_i` 是离散认知偏见：

- 更信高声誉者
- 更信同社群消息
- 更信强烈或频繁消息
- 折扣跨社群消息

这相当于把复杂贝叶斯更新压缩成游戏友好的局部启发式。

## 隐藏真相与私有信号

每局有一个全局隐藏状态：

```text
theta in {0, 1}
```

隐藏真相给系统提供真正的信息含量。没有它，游戏就只剩纯粹站队。

主体有时会收到私有信号：

```text
s_i in {0, 1}
```

信号是有噪声的。不同关卡和特殊节点会改变信号出现率和准确率。支持某一状态的信号会推动信念一步：

```text
if s_i = 1: b_i += 1
if s_i = 0: b_i -= 1
b_i 被裁剪到 [-2, 2]
```

## 邻域与网络结构

可见地图是格子，但底层图不只是方格网络。

每个格子拥有：

- 周围 Moore 邻域连接
- 根据地图区域划分的社群身份
- 少量跨社群桥接边

这同时保留：

- 方格局部性，让元胞自动机可读
- 小世界捷径，让长程瀑布和谣言爆发成为可能
- 社群分区，让回音室和极化自然出现

## 同步回合规则

每一回合所有格子同步经历六个阶段。

### 1. 私有信号

每个主体以关卡参数决定的概率和准确率收到关于隐藏真相的有噪声信号。

### 2. 生成消息

主体会把信念策略性编码成对外发言：

```text
if b_i >= 1: 倾向于 m_i = 1
if b_i <= -1: 倾向于 m_i = -1
if b_i = 0: 通常 m_i = 0
```

类型会改写这个基础规则：

- 求真者只有在 `|b_i| >= 2` 时发言。
- 从众者会偏向上一轮局部多数。
- 投机者会放大更容易获得注意力的消息。
- 煽动者即使证据弱也会强烈表达。

### 3. 邻域聚合

每个节点把邻居消息聚合成局部压力场：

```text
I_i = sum_{j in N(i)} w_ij * m_j
```

权重可以由声誉、社群、注意力和平台机制决定：

```text
w_ij = 1 + alpha * r_j
```

认知滤镜和机制按钮也会修改权重，例如是否显示声誉、是否热门优先、是否允许匿名、是否允许跨社群传播。

### 4. 更新信念

信念由三股力量共同推动：

```text
b_i_new = clip(b_i + P_i + C_i + A_i, -2, 2)
```

其中：

- `P_i` 是私有信号推动。
- `C_i` 是邻域共识推动。
- `A_i` 是注意力或极端化推动。

不同类型使用不同阈值。求真者需要更强证据；从众者更容易移动；顽固者抵抗反向压力；投机者对注意力更敏感。

### 5. 选择行动

行动不等于发言：

```text
if b_i >= 1: a_i = 1
if b_i <= -1: a_i = 0
if b_i = 0: 沿用旧行动
```

这样就保留了四层结构：

```text
真相 -> 信念 -> 消息 -> 行动
```

如果这四层塌成一层颜色，游戏就只剩普通感染扩散。

### 6. 更新声誉与能量

每隔若干回合会揭示局部结果：

- 发对且被验证的消息提高声誉
- 错误且影响大的消息降低声誉
- 剧烈反复横跳降低可信度
- 获得注意力可以恢复发言能量
- 强烈发言会消耗更多能量

这创造了长期张力：博眼球可能短期占优，但准确性会在重复验证中积累长期影响力。

## 玩家角色

玩家最好不要直接控制每个格子。这个游戏最强的形态是让玩家控制机制层，或进行少量局部干预。

### 平台设计者

玩家可以调整：

- 是否显示声誉
- 是否热门优先
- 是否允许跨社群曝光
- 是否允许匿名发言
- 是否启用事实核查

这最接近信息设计和机制设计。

### 隐形操盘者

玩家拥有有限干预：

- 真相种子
- 事实核查节点
- 假高信誉节点
- 煽动者
- 桥接边

乐趣在于只改变很少的局部条件，却让整个网络走向完全不同的历史。

## 计分

游戏避免单一的“感染全图”胜利条件，而使用三条轴。

### 真相分

真相收敛衡量全网行动与隐藏真相的一致程度：

```text
T = (1 / n) * sum_i 1[a_i = theta]
```

### 极化分

极化衡量不同社群之间平均信念的差异：

```text
P = Var_community(mean_b_c)
```

值越高，代表社群层面的信念越分裂。

### 活跃分

活跃度衡量消息总量：

```text
E = (1 / n) * sum_i 1[m_i != 0]
```

这些指标之间存在真实张力：

- 真相高，活跃可能低
- 活跃高，极化可能也高
- 降低极化，可能压制发言

## 平台机制

原型中提供了几个机制按钮：

- 显示声誉：高信誉节点形成可见中心。
- 热门优先：加速瀑布，也可能增加极化。
- 跨区传播：可能纠偏，也可能让谣言长程爆发。
- 匿名发言：降低声誉成本，增加噪声。
- 事实核查：加入高准确率、低传播性的纠偏节点。

## 关卡

- 真相稀缺：真实信号少，谣言更容易赢。
- 两极社群：初始社群偏见强，目标是打穿回音室。
- 匿名洪水：错误传播的信誉成本下降。
- 爆款平台：热门推荐放大信息瀑布。
- 桥节点危机：跨区节点被污染后会触发大范围翻转。
- 注意力市场：投机传播更强，求真者必须靠长期声誉生存。

## 设计准则

核心原则是：

> 用离散局部规则模拟连续复杂博弈；用可视图样呈现抽象信息结构；用少量玩家干预撬动大规模社会涌现。

## 运行

```bash
npm install
npm run dev
```

当前原型使用 Vite + React + Canvas。Canvas 会铺满整个视口，模拟网格随窗口大小重新生成。界面默认英文，并提供 8 门语言切换；`Theory` 按钮会打开完整理论说明和参考文献模态框。

生产构建：

```bash
npm run build
```
